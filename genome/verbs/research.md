# verb: research

- `research.deep(topic, depth=1..3)` — expand into sub-queries, read sources, synthesize a cited brief (markdown artifact)
- `research.compare(items, criteria)` — table comparison with sources
- `research.monitor(query, frequency_mins=360)` — tracker that re-checks and alerts on change

Rules: lead with the conclusion; separate verified from inferred; name the strongest sources; state the material caveat.
